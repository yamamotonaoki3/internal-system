# 0010：日本語の全文検索はD1のFTS5 trigramで行い、1〜2文字はLIKEで補う

- 状態：採用（本番での動作の確認は未了）
- 日付：2026-11-02（利用者の承認は2026-11-02〜03）
- 関係：Issue #105、決定記録 T-03・C-152、`docs/requirements/04-search.md`、決定C-88・C-127、調査T-05、調査メモ[T-03 日本語全文検索の方式](../research/T-03-japanese-search.md)・[D1のみ構成でのスパイク](../research/spike-d1-hash.md)

## 背景

メッセージなどを日本語で検索できる必要がある（機能4）。検索語は100文字まで、p95で2秒以下（C-88）。規模は全体で数十万件程度である。DBはD1のみ（ADR-0005）。

FTS5の標準のトークナイザ`unicode61`は空白と記号でしか区切らず、日本語はそのままでは使えない。D1の`LIKE`/`GLOB`のパターンは50バイトまでで、日本語は1文字3バイトのため、約16文字までしか表せない（検索語100文字を満たせない）。

## 選択肢

1. FTS5の`trigram`：部分一致が日本語でそのまま使える。3文字未満の語は索引で引けない
2. アプリ側の分かち書き（`Intl.Segmenter`など）＋FTS5：分け方の違いで検索漏れが出る
3. 1文字ずつ空白で区切って`unicode61`に入れる：1〜2文字の検索も同じ仕組みで解ける。索引が大きくなる
4. `LIKE`だけ：50バイト制限のため単独では不可
5. 外部の検索サービス：今回の規模では採用する根拠が弱く、社内の個人情報を含む本文を外部へ複製するコストがある
6. PostgreSQLの日本語検索：DBをD1のみにしたため（ADR-0005）採らない

## 決定

**D1のFTS5のtrigramを使う**。

- **3文字以上の検索語は`MATCH`で解く**
- **1〜2文字の検索語は`LIKE`で補う**。検索語が短いので、50バイトの制限内に収まる。1〜2文字の`MATCH`は、エラーにならずに0件を返すため、使わない
- **部屋・期間の絞り込みと併用する**（全件の走査を避ける）
- **索引に入れる本文**は、**マークダウンの記号を除いた本文**にする。**添付ファイル名・案件の件名を同じ索引に入れ**、**種類を列で区別して絞り込めるようにする**。TODOの本文は、後から追加できる形にしておく
- **性能は実装時に実測する**：30万件の架空データ（`[PERF_TEST]`のタグ）で、検索語1・2・3・10・50・100文字の応答時間（p50・p95）、読み取り行数、索引後のDBサイズ、投稿・編集・削除の書き込みの重さを測る（調査メモT-03の7章）
- FTS5の仮想テーブル・トリガーは、生SQLのマイグレーションで作る可能性がある。drizzle-kitが仮想テーブルの差分を誤って消さないかを、導入前に確かめる

### 本番での未確認事項

- **本番のD1で、trigramが動くこと**（ローカルの`wrangler dev`では、作成・3文字以上と100文字の`MATCH`・`LIKE`の動作を確認した）
- **FTS5を含むDBで、Time Travelの復元ができること**（公式に記載がなく未確認。検証用のDBで確かめる）

これらが確認できない場合は、調査メモの第2候補（1文字区切り）を検討する。切り替えるときは新しいADRを追加する。

## 理由

- SQLだけで書けて実装が軽く、部分一致が日本語でそのまま使える
- 1〜2文字は`LIKE`で補えば、`MATCH`の弱点を埋められる。全件の走査になるため、部屋・期間の絞り込みと併用して件数を抑える
- FTS5を含むDBは`wrangler d1 export`で書き出せないが、C-127で定期エクスポートを設けず、復旧はTime Travelと決めているため、バックアップ方針とは衝突しない
- 種類を列で区別して同じ索引に入れれば、メッセージ・添付ファイル名・案件の件名を1つの検索で扱える

## 影響

- 手動エクスポートが必要になった場合（移行・調査）は、仮想テーブルを削除して書き出し、`'rebuild'`で索引を作り直す手順になる。手順の文書化と検証が要る
- 索引は書き込みのたびに更新される。D1の書き込み行数の課金に効くため、実測で確かめる
- 添付・案件の公開範囲の変更（C-10など）が索引に反映されるよう、検索結果は権限で絞り込む。検索の対象と公開範囲の細部は`docs/requirements/04-search.md`のとおり
- 見直す条件：本番のD1でtrigramが動かない、p95で2秒を満たせない
