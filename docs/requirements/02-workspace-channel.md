# 機能2：ワークスペースとチャンネルの管理

ワークスペースの作成、チャンネル（公開・非公開）の作成と承認、招待、オーナーの管理者権限。全体の入口は [要件定義書](../requirements.md)。

## 機能要件

| # | 機能 | 内容 | 受け入れ条件 |
| --- | --- | --- | --- |
| 2-1 | ワークスペースの作成 | ワークスペースを新規に作る。作った人がオーナーになる | AC-1：ワークスペースを作成できる<br>AC-2：作成した人が、オーナーとして管理者の権限を持つ<br>AC-3：ワークスペースのメンバーでない人には、その中身が見えない |
| 2-2 | チャンネルの作成と承認 | ワークスペースに、チャンネルを新規に作る。公開と非公開を選ぶ。作成には、部署管理者の承認と、管理者の承認が必要 | AC-1：メンバーが、公開・非公開を選んでチャンネルの作成を申請できる<br>AC-2：部署管理者の承認、管理者の承認が揃うまで、チャンネルとして使えない<br>AC-3：承認・却下の履歴が残る。承認・却下は、重要な操作として再認証される<br>（ここでの「管理者」は全体管理者を指すと解釈している。「未決定事項」[#2](../requirements.md)） |
| 2-3 | 公開チャンネル | ワークスペースのメンバーなら誰でも参加できる | AC-1：ワークスペースのメンバーは、公開チャンネルを一覧で見て、自分で参加できる<br>AC-2：ワークスペースのメンバーでない人は参加できない |
| 2-4 | 非公開チャンネル | 招待された人だけが参加できる | AC-1：招待されていない人には、チャンネルの存在・内容が見えない（一覧にも出ない）<br>AC-2：招待は、チャンネルの参加者のうち、許可された人だけが行える<br>AC-3：招待は、重要な操作として再認証される |
| 2-5 | 友人の招待・参加の許可 | ワークスペース・チャンネルに、同じ会社の社員を招待し、参加を許可する | AC-1：招待された社員が、参加を申し込める<br>AC-2：参加は、許可する権限を持つ人が許可するまで有効にならない<br>AC-3：アカウントのない人（社外の人）は招待できない<br>（招待できる人・方法は「未決定事項」[#6](../requirements.md)） |
| 2-6 | オーナーの管理者権限 | ワークスペースのオーナーが、メンバーやチャンネルを管理する | AC-1：オーナーだけが、管理の操作ができる<br>（できる操作の一覧は、元の指示が途中で切れているため、「未決定事項」[#2](../requirements.md)で確定する） |
