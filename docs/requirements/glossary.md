# 用語集

**案（合意前）**

Issue #21 の成果物。既存文書の用語と参照先をまとめた案であり、新しい要件を決める文書ではない。要件定義書全体は合意前のドラフトである。「決定」は参照元で利用者が決めた事項、「案」は確認前の提案、「未決定」はまだ選ばれていない事項を表す。

## 1. 読み方と参照する文書

内容が食い違う場合の優先順位は次のとおり。

1. [権限表](permissions.md)の4.1（決定一覧）と3章の表
2. [要件定義書](../requirements.md)と機能別の受け入れ条件：[共通（土台）](00-foundation.md)、[メッセージング](01-messaging.md)、[ワークスペース・チャンネル](02-workspace-channel.md)、[通知](03-notification.md)、[検索](04-search.md)、[案件](05-case.md)、[ステータス](06-status.md)、[部署](07-department.md)
3. [データモデル](data-model.md)
4. [画面構成](screens.md)

以下の「データ」は data-model.md のテーブル名・列名で、すべて設計案であり、実装済みのDBを意味しない。`テーブル.列`で記す。「画面」は screens.md の画面IDと画面名。「機能」は上記の機能別文書の番号であり、`0-4 AC-10`のように機能番号と受け入れ条件を組にして読む。主要な対応先を載せ、全参照先の列挙はしない。
