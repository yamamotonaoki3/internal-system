# 機能1：メッセージング

チャンネル・ダイレクトメッセージでのやり取り（投稿・編集・返信・添付・リアクション・メンション・リアルタイム更新）。全体の入口は [要件定義書](../requirements.md)。

## 機能要件

| # | 機能 | 内容 | 受け入れ条件 |
| --- | --- | --- | --- |
| 1-1 | チャンネルのテキストチャット | チャンネルに、テキストのメッセージを投稿する | AC-1：参加しているチャンネルに投稿できる<br>AC-2：参加していないチャンネルには、投稿も閲覧もできない（公開チャンネルは参加すれば可能） |
| 1-2 | ダイレクトメッセージ | 特定の相手と1対1でメッセージを送る。不在の相手への用件の伝達（伝言）は、この機能で行う（グループは「未決定事項」[#12](../requirements.md)） | AC-1：ほかのメンバーにダイレクトメッセージを送れる<br>AC-2：やり取りは、当事者だけが閲覧できる<br>AC-3：相手が不在でも送れ、相手がログインしたときに読める |
| 1-3 | メッセージの編集・削除 | 自分のメッセージを編集・削除する | AC-1：自分のメッセージを編集・削除できる<br>AC-2：他人のメッセージは編集できない<br>AC-3：編集したメッセージには「編集済み」と表示される<br>AC-4：削除は再認証の対象（[0-5](00-foundation.md)）。方式と、他人のメッセージを削除できる人は「未決定事項」[#11](../requirements.md) |
| 1-4 | 返信 | メッセージに返信する（スレッド） | AC-1：メッセージに返信でき、返信が元のメッセージに紐づいて表示される<br>AC-2：元のメッセージが削除されても、返信の表示が壊れない |
| 1-5 | マークダウンの表示 | マークダウンは必須ではない。マークダウン記法で書いたメッセージは整形して表示できる。記法を使わないテキストだけのメッセージも、そのまま表示できる | AC-1：マークダウン記法を使わないテキストだけのメッセージも、問題なく投稿・表示できる<br>AC-2：マークダウン記法で書いたメッセージは、整形されて表示される（対応する記法は「未決定事項」[#13](../requirements.md)）<br>AC-3：HTMLやスクリプトを書いても実行されない（XSSの対策） |
| 1-6 | 添付 | 画像・動画・ファイルを添付する。ファイルはR2に保存し、権限のある人だけがダウンロード・閲覧できる | AC-1：画像・動画・ファイルを添付でき、許可していない形式・サイズは拒否される（C-63）<br>AC-2：添付ファイルは、そのメッセージを見られる人だけが取得できる（保存先のURLを誰にでも見える形で公開しない）<br>AC-3：上限サイズを超えるファイルは、保存される前に拒否される<br>（上限サイズは「未決定事項」[#10](../requirements.md)） |
| 1-7 | リアクション・スタンプ | メッセージに、絵文字のリアクションと、「いいね」「了解」などのスタンプを付ける | AC-1：メッセージに絵文字のリアクションを付けられる<br>AC-2：「いいね」「了解」などのスタンプを付けられる<br>AC-3：同じリアクションの数と、付けた人が分かる。付けたものは取り消せる<br>（絵文字・スタンプの出どころは「未決定事項」[#14](../requirements.md)） |
| 1-8 | メンション | メッセージの中で、特定のメンバーを指名する（@表示名） | AC-1：@で入力候補が出て、メンバーを指名できる<br>AC-2：指名された人に通知される（[3-2](03-notification.md)）<br>AC-3：そのチャンネルを見られない人には、指名しても内容が届かない<br>（全員宛ての指名は「未決定事項」[#12](../requirements.md)） |
| 1-9 | リアルタイム更新 | 他の人のメッセージ・リアクションが、画面を再読み込みせずに反映される | AC-1：同じチャンネル・ダイレクトメッセージを開いている他の人のメッセージが、再読み込みなしで表示される<br>（方式はADRで決める。「未決定事項」[#7](../requirements.md)） |

## 関連するAPI

API仕様書は `docs/api/openapi.json`。operationIdは設計の段階で埋める。

| 受け入れ条件 | 必要な操作 | operationId |
| --- | --- | --- |
| 1-1（AC-1〜AC-2） | チャンネルにメッセージを投稿する・閲覧する | 未割当 |
| 1-2（AC-1〜AC-3） | ダイレクトメッセージを送る・閲覧する | 未割当 |
| 1-3（AC-1〜AC-4） | メッセージを編集する・削除する | 未割当 |
| 1-4（AC-1〜AC-2） | メッセージに返信する | 未割当 |
| 1-5（AC-1〜AC-3） | マークダウンのメッセージを投稿・表示する | 未割当 |
| 1-6（AC-1〜AC-3） | ファイルを添付する・取得する | 未割当 |
| 1-7（AC-1〜AC-3） | リアクション・スタンプを付ける・取り消す | 未割当 |
| 1-8（AC-1〜AC-3） | メンバーを指名する（入力候補を取得する） | 未割当 |
| 1-9（AC-1） | メッセージ・リアクションの更新をリアルタイムに受け取る | 未割当 |

## この機能に関わる未決定事項

全件の正は [要件定義書の「7. 未決定事項」](../requirements.md) の表とする。

- #7：リアルタイム更新の方式（Durable Objects・WebSocket等。ADRで決める）
- #10：添付ファイルの上限サイズと許可する形式の一覧
- #11：メッセージ・添付ファイルを削除できる人と、削除の方式
- #12：グループのダイレクトメッセージを作るか。全員宛ての指名を作るか
- #13：マークダウンの記法の範囲と、使うライブラリ
- #14：絵文字・スタンプの出どころ
