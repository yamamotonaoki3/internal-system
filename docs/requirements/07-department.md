# 機能7：部署の連絡と所属一覧

部署の専用チャンネル、部署のお知らせ、社員の一覧。全体の入口は [要件定義書](../requirements.md)。

## 機能一覧

| # | 機能 | 概要 |
| --- | --- | --- |
| 7-1 | 部署の専用チャンネル | 部署の社員だけが見られるチャンネルを自動で作る |
| 7-2 | 部署のお知らせ | 部署管理者が部署の社員へお知らせを投稿する |
| 7-3 | 社員の一覧 | 社員の一覧を見て、部署で絞り込む |

## 機能要件

### 7-1 部署の専用チャンネル

部署を作ると、その部署の社員だけが見られるチャンネルが自動で作られる。部署を作れるのは全体管理者のみ（決定）。部署とワークスペースの関係と、部署の作成時に部署管理者を指定できるかは「未決定事項」[#3](../requirements.md)

**受け入れ条件**

- AC-1：部署の作成と同時に、専用チャンネルができる
- AC-2：専用チャンネルは、その部署の社員だけが見られる
- AC-3：部署を作成できるのは、全体管理者のみ。部署管理者・ワークスペースのオーナー・一般のメンバーには、作成の画面もメニューも出ず、APIも使えない

### 7-2 部署のお知らせ

部署管理者が、部署の社員へお知らせを投稿する。社員は閲覧のみ

**受け入れ条件**

- AC-1：お知らせを投稿できるのは、その部署の部署管理者だけ
- AC-2：部署の社員は閲覧できる。他の部署の社員は見られない

### 7-3 社員の一覧

表示名・部署・内線番号・メールアドレス・ステータスを、一覧で見る。部署で絞り込める

**受け入れ条件**

- AC-1：ログインしたメンバーは、一覧を閲覧できる
- AC-2：一覧に表示する項目は、表示名・部署・内線番号・メールアドレス・ステータスのみ（本名は一覧に出さない。AC-4）
- AC-3：部署で絞り込める
- AC-4：一覧の表示名を押す（タップする）と、プロフィールカード（画面S-27）で、その人の本名を確認できる（[0-4](00-foundation.md) AC-10。本名を見られる人は「未決定事項」[#21](../requirements.md)）
