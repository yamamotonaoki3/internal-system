# 機能6：ステータスの共有

在席状況（在席・外出・欠席・休暇・会議中）を共有する。全体の入口は [要件定義書](../requirements.md)。

不在時の連絡は、ダイレクトメッセージ（[1-2](01-messaging.md)）で行う。専用の「伝言」機能は作らない。

## 機能要件

### 6-1 ステータスの共有

[0-4](00-foundation.md)で設定したステータス（在席・外出・欠席・休暇・会議中、戻り予定）が、社員一覧・ダイレクトメッセージの相手の選択・プロフィールカードの画面で分かる。部署とステータスは、一緒に見える

**受け入れ条件**

- AC-1：相手のステータスと戻り予定が、ダイレクトメッセージの画面（S-06）の相手の表示で分かる（相手を選ぶ段階の表示は AC-4）【C-165により追記（2026-11-11）：DMの画面S-06での表示はIssue #136に回す。Issue #130は表示部品（`StatusBadge`・`ProfileCardTrigger`）と取得APIを用意した。元の記述は残す】【C-168により追記（2026-11-12）：DMの画面S-06での表示は Issue #136 で実装した（上部に相手のステータスと戻り予定。戻り予定を過ぎたら「戻り予定を過ぎています」を出す）。無効な相手はステータスを出さず「退職者」と併記する。元の記述は残す】
- AC-2：ステータスを変えると、他の人の画面に反映される。本人は、プロフィール設定（S-19）のほか、ヘッダーのアバターメニューからも切り替えられる（C-79）。【C-136により追記（2026-11-02）：ヘッダー（検索・通知・アバターの並び）に、現在のステータスを示すボタンを置く。押すと5種類から選んで直接切り替えられ、戻り予定も同じ場所で入力できる。アバターメニューとS-19の切り替えは残す。スマートフォンのボタンは色つきの丸だけを表示する。表示の細部、一言メッセージを同じ場所で入力できるか、ステータスの自動切り替え（戻り予定を過ぎても自動では変わらない規則は0-4 AC-4のまま）は**未決定**】【C-165により追記（2026-11-11）：Issue #130で、ヘッダーのボタン・アバターメニュー・S-19の切り替えを実装した。色の割り当て（在席=緑・外出=黄・欠席=赤・休暇=青・会議中=紫）を決めた。一言メッセージはS-19だけで入力する。元の記述は残す】
- AC-3：ステータスの種類は、在席・外出・欠席・休暇・会議中の5種類である（「会議中」を足した。決定。[0-4](00-foundation.md)）
- AC-4：社員一覧（[7-3](07-department.md)）・ダイレクトメッセージの相手を選ぶ画面（選択時。[1-2](01-messaging.md) AC-5。DMの画面での表示は AC-1）・プロフィールカード（[0-4](00-foundation.md) AC-10）で、その人の部署とステータスが一緒に見える【C-165により追記（2026-11-11）：社員一覧（S-20）とプロフィールカード（S-27）はIssue #130で実装した。DMの相手選択での表示はIssue #136に回す。元の記述は残す】【C-168により追記（2026-11-12）：DMの相手を選ぶ画面（`/dms/new`）での部署とステータスの表示は Issue #136 で実装した（文字つき）。元の記述は残す】
