# 機能6：ステータスの共有

在席状況（在席・外出・欠席・休暇・会議中）を共有する。全体の入口は [要件定義書](../requirements.md)。

不在時の連絡は、ダイレクトメッセージ（[1-2](01-messaging.md)）で行う。専用の「伝言」機能は作らない。

## 機能要件

### 6-1 ステータスの共有

[0-4](00-foundation.md)で設定したステータス（在席・外出・欠席・休暇・会議中、戻り予定）が、社員一覧・ダイレクトメッセージの相手の選択・プロフィールカードの画面で分かる。部署（＝ワークスペース）とステータスは、一緒に見える

**受け入れ条件**

- AC-1：相手のステータスと戻り予定が、ダイレクトメッセージの画面（S-06）の相手の表示で分かる（相手を選ぶ段階の表示は AC-4）
- AC-2：ステータスを変えると、他の人の画面に反映される
- AC-3：ステータスの種類は、在席・外出・欠席・休暇・会議中の5種類である（「会議中」を足した。決定。[0-4](00-foundation.md)）
- AC-4：社員一覧（[7-3](07-department.md)）・ダイレクトメッセージの相手を選ぶ画面（選択時。[1-2](01-messaging.md) AC-5。DMの画面での表示は AC-1）・プロフィールカード（[0-4](00-foundation.md) AC-10）で、その人の部署（＝ワークスペース）とステータスが一緒に見える
