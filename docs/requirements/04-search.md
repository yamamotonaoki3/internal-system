# 機能4：検索

メッセージ・案件の検索。全体の入口は [要件定義書](../requirements.md)。

## 機能一覧

| # | 機能 | 概要 |
| --- | --- | --- |
| 4-1 | メッセージ検索 | キーワードでメッセージを検索する |
| 4-2 | 案件の検索 | キーワードで案件とそのやり取りを検索する |

## 機能要件

### 4-1 メッセージ検索

キーワードで、メッセージを検索する

**受け入れ条件**

- AC-1：キーワードで、自分が見られるメッセージだけが検索結果に出る
- AC-2：参加していないチャンネルや、他人のダイレクトメッセージは、検索結果に出ない

### 4-2 案件の検索

キーワードで、案件とそのやり取りを検索する（メール検索の代替）

**受け入れ条件**

- AC-1：すべての案件を検索結果の対象とする（終了した案件も含む。決定。権限表 Q-38、5-1 AC-12）。参加者は、これまでどおり件名・メッセージ・添付・TODOなどを検索できる。参加者でない人が検索できるのは件名だけである
- AC-2：参加者でない人の検索結果には、件名・状態（進行中／終了）・案件が属するワークスペース名・進捗だけを出す（決定。Q-38）。説明・参加者・メッセージ・TODOの項目・添付・案件専用チャンネルの内容は出さない。進捗をTODOの進捗と読むのは導いた内容、表示形式「完了数/全体数」は案、0件は「項目なし」とするのは決定（5-4 AC-4）。開くと「参加者だけが見られます（非公開）」と表示する（決定。5-1 AC-14）。案件専用チャンネル自体は、非参加者のチャンネル一覧・メッセージ検索には出さない（5-2 AC-6）
