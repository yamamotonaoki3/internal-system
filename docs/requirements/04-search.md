# 機能4：検索

メッセージ・案件の検索。全体の入口は [要件定義書](../requirements.md)。

## 機能一覧

| # | 機能 | 概要 |
| --- | --- | --- |
| 4-1 | メッセージ検索 | キーワードでメッセージを検索する |
| 4-2 | 案件の検索 | キーワードで案件とそのやり取りを検索する |

## 機能要件

### 4-1 メッセージ検索

キーワードで、メッセージを検索する

**受け入れ条件**

- AC-1：キーワードで、自分が見られるメッセージだけが検索結果に出る
- AC-2：参加していないチャンネルや、他人のダイレクトメッセージは、検索結果に出ない
- AC-3：検索語は1〜100文字とする。1文字の検索も認める（決定。C-90。4-2にも適用する）

### 4-2 案件の検索

キーワードで、案件とそのやり取りを検索する（メール検索の代替）

**受け入れ条件**

- AC-1：終了した案件も含むすべての案件の件名を検索対象とする。参加者は件名・メッセージ・添付・TODOなどを検索できる。非参加者は、参加者限定の案件では件名と、全社員に見える案件番号・取引先名だけを検索できる（AC-3）。全社員公開が承認されたアーカイブでは、件名・メッセージ・TODO・「全社員公開アーカイブで公開できる」添付のファイル名を検索できる。添付の内容や参加者限定添付のファイル名・内容は検索対象にしない（C-64・C-65）。
- AC-2：参加者限定の案件では、非参加者が検索できる範囲は件名と、全社員に見える案件番号・取引先名（AC-3）とし、結果の概要は件名・状態・所属部署・進捗・納期に案件番号・取引先名を加えた項目だけで、内容を出さない（検索できる範囲と、結果に表示する概要の項目は別。納期を結果の概要に含めることは決定。5-1 AC-17、C-87）。全社員公開が承認されたアーカイブでは、検索に一致した公開範囲内のメッセージ・TODO・公開可能な添付名を結果に含めてよい。参加者限定添付のファイル名・内容は、検索結果・抜粋・件数からも漏らさない。0件の進捗は「項目なし」、表示形式は「完了数/全体数」の数字と進捗バーの併用でパーセントは出さない（決定。C-84、5-4 AC-4）。開いた際の閲覧は5-1 AC-2に従い、公開・審査用閲覧の例外に該当しなければ非公開の案内を示す。専用チャンネルは通常のチャンネル一覧に出さない。
- AC-3：案件番号と取引先名でも検索できる。この2つは全社員に見える概要の項目なので、参加者限定の案件でも非参加者が検索できる（導いた内容）。検索語は4-1 AC-3に従う（決定。C-89）。案件番号の検索で前方一致などを使う方式は未決定

2026-10-22の更新：全社員公開が承認された案件アーカイブは、公開範囲内の件名・メッセージ・TODO・公開可能な添付ファイル名を非参加者も検索できる。参加者限定添付の名前・内容は検索対象外とし、審査用の一時閲覧権限は検索権限へ広げない（C-64・C-65）。
