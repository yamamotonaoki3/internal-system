# 機能4：検索

メッセージ・案件の検索。全体の入口は [要件定義書](../requirements.md)。

## 機能一覧

| # | 機能 | 概要 |
| --- | --- | --- |
| 4-1 | メッセージ検索 | キーワードでメッセージを検索する |
| 4-2 | 案件の検索 | キーワードで案件とそのやり取りを検索する |

## 機能要件

### 4-1 メッセージ検索

キーワードで、メッセージを検索する

**受け入れ条件**

- AC-1：キーワードで、自分が見られるメッセージだけが検索結果に出る
- AC-2：参加していない非公開チャンネルや、他人のダイレクトメッセージは、検索結果に出ない。一方、未参加の公開チャンネルのメッセージは、検索の対象にする（決定。C-117、Q-48。C-94の【案：対象にする】を確定）。公開チャンネルは参加しなくても読める（C-94）ため、4-1 AC-1の「自分が見られるメッセージ」に含める。検索の対象外のまま変わらないのは、参加していない非公開チャンネル・当事者でないDM・閲覧権限のない案件の中身である（参加している非公開チャンネル・当事者のDM・参加者である案件は、見られるメッセージとして検索できる）
- AC-3：検索語は1〜100文字とする。1文字の検索も認める（決定。C-90。4-2にも適用する）【C-152により追記（2026-11-02〜03。Issue #105）：検索の方式は、D1のFTS5 trigramとする。3文字以上は`MATCH`、1〜2文字は`LIKE`で補う（検索語が短いので50バイト制限内）。部屋・期間の絞り込みと併用する。索引には、マークダウンの記号を除いた本文に、添付ファイル名・案件の件名を同じ索引に入れる（種類を列で区別して絞り込む。TODOは後から追加できる）。性能は実装時に実測する（30万件・検索語1・2・3・10・50・100文字）。本番でのtrigramの動作とFTS5を含むDBでのTime Travel復元は未確認。[ADR-0010](../adr/0010-japanese-search-fts5-trigram.md)。元の記述は残す】
- AC-4【案】（C-144。Issue #104。プロトタイプの案。決定ではない）：未参加の公開チャンネルのメッセージが検索結果に出るときは、「参加していません」の表示を添える（文言は案。Q-27）

**実装の状況（Issue #155 の155-A。2026-11-20。C-200。元の記述は残す）**

- 満たした範囲：AC-1・AC-2（見られるメッセージだけ。未参加の公開チャンネルは出る。参加していない非公開チャンネル・当事者でない DM・参加していない案件の部屋は出ない。全体管理者・オーナーも同じ）、AC-3 のうちメッセージの本文（1〜100文字。3文字〔コードポイント〕以上は`MATCH`、1〜2文字は`LIKE`ではなく`instr`〔D-3。C-168 と同じ〕。部屋・期間の絞り込み。記号を除いた本文の索引）。API は EP-4-01（`searchMessages`）、画面は S-15 とヘッダーの検索欄。設計は [search.md](../design/search.md)
- **残り**：添付ファイル名の索引（155-B）、案件の件名（155-C。4-2）
- 【155-B（2026-11-21。C-201）】AC-3 のうち添付ファイル名を満たした：見られるメッセージに結び付いた添付のファイル名で、そのメッセージが1件として出る（本文と名前が両方一致しても1件）。結果には「ファイル名で一致」の印と一致した名前が付く。名前は記号を除かずに索引に入れる。見えない部屋・削除済みのメッセージ・未投稿の添付・権限で除く部屋の添付の名前は、結果・次の有無・カーソルに出ない。「ファイル名だけ」の絞り込みは作らない。**残り**：案件の件名・案件番号・取引先名（155-C）
- 【155-C（2026-11-21。C-202）】AC-3 の検索語の規則（1〜100文字。件名は3文字以上`MATCH`・1〜2文字`instr`）を、案件の検索（EP-4-02）にも当てた。これで、4-1 の検索の対象（メッセージの本文・添付ファイル名）と、4-2 の案件の件名・案件番号・取引先名がそろった
- AC-4【案】の「参加していません」の表示は作っていない（決定ではないため）
- 本番での動作の確認・30万件の実測は #160

### 4-2 案件の検索

キーワードで、案件とそのやり取りを検索する（メール検索の代替）

**受け入れ条件**

- AC-1：終了した案件も含むすべての案件の件名を検索対象とする。参加者は件名・メッセージ・添付・TODOなどを検索できる。非参加者は、参加者限定の案件では件名と、全社員に見える案件番号・取引先名だけを検索できる（AC-3）。全社員公開が承認されたアーカイブでは、件名・メッセージ・TODO・「全社員公開アーカイブで公開できる」添付のファイル名を検索できる。添付の内容や参加者限定添付のファイル名・内容は検索対象にしない（C-64・C-65）。
- AC-2：参加者限定の案件では、非参加者が検索できる範囲は件名と、全社員に見える案件番号・取引先名（AC-3）とし、結果の概要は件名・状態・担当部署・進捗・納期に案件番号・取引先名を加えた項目だけで、内容を出さない（検索できる範囲と、結果に表示する概要の項目は別。納期を結果の概要に含めることは決定。5-1 AC-17、C-87）。全社員公開が承認されたアーカイブでは、検索に一致した公開範囲内のメッセージ・TODO・公開可能な添付名を結果に含めてよい。参加者限定添付のファイル名・内容は、検索結果・抜粋・件数からも漏らさない。0件の進捗は「項目なし」、表示形式は「完了数/全体数」の数字と進捗バーの併用でパーセントは出さない（決定。C-84、5-4 AC-4）。開いた際の閲覧は5-1 AC-2に従い、公開・審査用閲覧の例外に該当しなければ非公開の案内を示す。専用チャンネルは通常のチャンネル一覧に出さない。
- AC-3：案件番号と取引先名でも検索できる。この2つは全社員に見える概要の項目なので、参加者限定の案件でも非参加者が検索できる（導いた内容）。検索語は4-1 AC-3に従う（決定。C-89）。案件番号の検索は前方一致（先頭からの一致だけ）とする（決定。C-117）。【C-129・C-130により追記（2026-10-31）：取引先を再編集で変えても案件番号は変わらないため、案件番号は発行時の番号で引ける。取引先名の検索は現在の取引先の名前で引ける（発行時の取引先名でも引けるかは未決定）。結果の概要の「担当部署」は、すべての担当部署の名前（複数のときの並び順は未決定）。】入力の前後の空白は除き、大文字小文字は区別せず、ハイフンなし（`ABC261024`）の入力も一致させる（決定。C-120）

**実装の状況（Issue #155 の155-A。2026-11-20。C-200。元の記述は残す）**

- 満たした範囲：AC-1 のうち、参加者が、参加している案件の部屋のメッセージを検索できること（終了しただけの案件を含む。D-4）。参加していない人には、案件の部屋のメッセージは出ない。`perm.case.view`のない人には、案件の部屋を除く
- **残り**：案件の件名・案件番号・取引先名の検索と結果の概要（AC-1〜AC-3。155-C。EP-4-02）、添付ファイル名（155-B）、**全社員公開アーカイブの公開範囲を、参加していない人が検索すること**（AC-1・AC-2。D-4 で範囲外とし、親 #155 に残す。公開承認の仕組みがまだない）、**TODO の検索**（AC-1。D-5 で対象にしないとし、親 #155 に残す）。延期の2件があるため、155-A〜C が終わっても、4-2 の受け入れ条件をすべて満たした扱いにしない
- 【155-B（2026-11-21。C-201）】AC-1 の「参加者は…添付…を検索できる」のうちファイル名を満たした（参加者は、参加している案件の部屋の添付の名前で検索でき、参加者限定の添付も出る）。参加していない人には、参加者限定の添付の名前が、結果・抜粋・次の有無から漏れない（AC-2）。案件の添付の公開範囲は、参加者の検索の資格に使わない。**残り**：案件の件名・案件番号・取引先名（155-C）、全社員公開アーカイブ（公開できる添付の名前を含む）、TODO
- 【155-C（2026-11-21。C-202）】AC-1 のうち「終了した案件も含むすべての案件の件名」、AC-2 のうち参加者限定の案件の非参加者の結果の概要、AC-3 を満たした。件名・案件番号（先頭からの一致。前後の空白とハイフンにあたる文字を除き、全角の英数字は半角として、大小文字を区別しない）・いまの取引先名（部分一致）で、すべての案件（進行中・終了）が出る。参加者・参加していない部署のオーナー・全体管理者・一般の社員で、結果の案件は同じ。結果は概要の項目（件名・状態・担当部署〔すべての名前〕・進捗・納期・案件番号・取引先名）と参加の有無・一致した対象だけで、説明・参加者・最終更新などの内容は出さない。押すと S-17 へ移り、参加していない人には非公開の案内が出る。API は EP-4-02（`searchCases`）、画面は S-15 の「案件」の区画。設計は [search.md](../design/search.md)。全角の英数字・全角のハイフンなどで打った案件番号も、半角と同じに扱って一致する（利用者の決定。C-202 (5)。件名・取引先名の照合は変えない）。結果の行には、TODO の進捗も出す（AC-2）
- **残り（#155 の外に移した）**：全社員公開アーカイブの公開範囲を、参加していない人が検索すること（AC-1・AC-2。#356）、TODO の検索（AC-1。#357）。このため、**4-2 の受け入れ条件は、すべて満たした扱いにしない**。#155 は155-C で閉じる（利用者の決定 2026-11-21）
- 総件数は返さない（見えないものの存在が件数から推し量れないようにするため）

2026-10-30の注記（C-123。C-124で用語を改訂）：アーカイブ（C-123の「論理削除」）した案件・チャンネルは、一覧・検索の結果に出ない（決定。5-1 AC-22、2-6 AC-6）。物理削除した案件は、中身ごと消えるため検索の対象から消える。物理削除したチャンネルは、中のメッセージ・返信・リアクション・添付・未読を全部消すため（C-124で決定）、検索の対象から消える。復元すると、検索の対象に戻る。これは、案件の「終了」（終了した案件を検索できる規則。5-1 AC-12）とは別。検索の索引・結果の件数への反映の方法など、検索への細かい実装上の影響は設計で決める（設計-14）。

2026-10-22の更新：全社員公開が承認された案件アーカイブは、公開範囲内の件名・メッセージ・TODO・公開可能な添付ファイル名を非参加者も検索できる。参加者限定添付の名前・内容は検索対象外とし、審査用の一時閲覧権限は検索権限へ広げない（C-64・C-65）。
